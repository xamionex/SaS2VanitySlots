# SaS2VanitySlots

Vanity equipment slots for Salt and Sacrifice. Lets you change the visible appearance of each equipment slot to any item you have discovered or can craft, without affecting stats. Also supports a per-slot "naked" toggle that hides the visual for that slot.

Adds its own "Vanity" entry to the in-game pause menu and the main menu.

Registers with SaS2ModOptions:
- Show All Items toggle (when on, the vanity picker shows every item of the matching type, not just discovered/craftable ones; does not persist discovery)
- Naked Toggle keybind (rebindable)

Made with https://github.com/xamionex/SaltAndSacrificeBepInExTemplate
